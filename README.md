# 🧠 Anxiety Crisis AI

> Prototipo de inteligencia artificial para la detección y ayuda temprana en crisis de ansiedad.

---

## ⚠️ Aviso importante

Este proyecto es un **prototipo en etapa inicial** con fines de investigación y desarrollo.  
**No reemplaza la atención profesional en salud mental.**  
Si estás en una crisis, por favor comunícate con un profesional de salud mental o línea de crisis.

---

## 📌 ¿Qué es este proyecto?

`anxiety-crisis-ai` es una IA experimental diseñada para:

- 🔍 **Detectar señales tempranas** de crisis de ansiedad a través de texto o patrones de comportamiento
- 🤝 **Ofrecer una primera respuesta** empática y orientadora
- 📋 **Guiar al usuario** hacia recursos de ayuda profesional
- 📊 **Registrar patrones** para análisis (con consentimiento explícito del usuario)

## ⚙️ Instalación (próximamente)

```bash
# Clonar el repositorio
git clone https://github.com/TU_USUARIO/anxiety-crisis-ai.git
cd anxiety-crisis-ai

# Crear entorno virtual
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate

# Instalar dependencias
pip install -r requirements.txt

# Copiar variables de entorno
cp .env.example .env
```
